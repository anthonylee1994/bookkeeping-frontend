# 5.7 報表 `/summaries`

- Period segmented control：日、週、月
- 日期 picker 配合上一期／下一期
- 顯示收入、支出、淨額、分類分佈（收入／支出各一張）、帳戶分佈、期內交易
- 轉帳併入淨額卡下面一行（筆數 + 金額），不計入收入／支出／淨額
- 月報額外顯示「收支日曆」，放喺淨額卡之後：逐日淨收支（紅負綠正、0 為灰）；未到嘅日子留白，今日淺灰格；窄螢幕用精簡金額（千／萬／億）並可橫向滾動
- 日曆格可點：切換去該日嘅日報（`period=daily`、`date=<ISO>`）；未到嘅日子唔可點
- Weekly 清楚顯示星期一至星期日範圍
- Desktop 帳戶分佈同期內交易並排兩欄（分類分佈同樣兩欄）
- 分類分佈圖表 slice／row 可點去已套用 `category_id`（連 `kind`）filter 嘅交易頁；帳戶分佈 row 亦然（`account_id`）；未分類／未知帳戶唔可點
- 期內交易 row 顯示分類頭像（跟 dashboard 一致）
- Chart tooltip 可用 keyboard 觸發；旁邊提供資料表
- URL 保存 `period`、`date`、`page`

## AI 收支概況

- 放喺淨額卡（及轉帳行）之後、日曆之前；只喺 `weekly` / `monthly` 期間出現（日報太短、冇洞察價值，所以 `daily` 一律唔顯示亦唔發請求）；期間完全冇收入／支出交易就唔顯示
- 用淡藍底 + 藍框 + `SparklesIcon`（semantic token `ai.bg`／`ai.border`／`ai.fg`），同其他白色報表卡區分
- 每個 highlight 係白底 callout（`bg.panel` + `shadow="xs"` + 3px `ai.fg` 左邊線），字級 `md`，唔好再用同卡底同色嘅藍框
- 由後端 `GET /summaries/{period}/insight` 產生（只支援 `weekly` / `monthly`，見 backend `agent-specs/03`）；frontend 只負責顯示，唔會自己 call DeepSeek，亦唔會自行計數
- 顯示一段 2–3 句、結論式嘅概況 + 最多 3 個「發現」（唔可以同概況重覆），附「只供參考」提示；後端同期內每筆交易（連分類、商戶、用戶輸入嘅備註）一齊交 AI 分析，內容可以引用個別交易、商戶同備註
- Loading：`Skeleton` 行，`aria-live="polite"`；**唔會遮住**上面 deterministic 嘅數字
- 失敗（後端 502、AI 輸出被 reject、或無 `text`）顯示「暫時未能生成 AI 收支概況」+ 重試；重試帶 `refresh=1` 強制繞過後端 cache
- 數據指紋（`summaryInsightKey`）由 summary aggregate + 交易總數派生：**唔計分頁**（純粹轉頁唔會重新生成），但交易新增／修改／刪除、或轉期間／日期就會觸發。後端另以自己嘅 fingerprint 決定要唔要真係再叫 AI（同期同數據會回 cache）
